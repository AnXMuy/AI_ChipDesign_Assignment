# 卷积硬件接口

`conv.sv` 是独立实现的可综合模块。输入和权重均为有符号 int8，乘积为有符号 16 位，累加寄存器为有符号 32 位。输出先执行算术右移 `SHIFT` 位，再饱和到 `[-128,127]`，不包含偏置与 ReLU。

## 参数与布局

- `H,W,CIN`：原始输入高、宽、通道数；`PAD`：四边补零宽度。
- `KERNEL_H,KERNEL_W,KERNELS`：卷积核高、宽、文件中保存的总输出通道数。
- `COUT`：实际计算前多少个输出通道，必须不大于 `KERNELS`。
- `STRIDE`：空间步幅；`OH,OW` 默认为标准卷积输出尺寸，也可由前端明确传入。
- `SHIFT`：量化算术右移位数，默认为 8；`LANES`：输入通道乘法器数量。

输入文件已由前端补零，硬件输入地址针对补零后的 `(H+2*PAD)×(W+2*PAD)` 空间。每个输入/权重存储字含 `CIN` 个 8 位通道，通道 0 位于最低 8 位。权重按 `[输出通道,核行,核列,输入通道]` 顺序保存，每个核空间位置占一个字。

## 时序

`rst_i` 是异步高电平复位。空闲状态下在时钟上升沿采样 `cfg_conv_start_i`，并锁存三个 20 位配置基址。运行期间的新启动信号被忽略，完成后可再次启动。

`ifm_vld_o` 与 `knl_vld_o` 同时发出一次读请求；外部存储器在请求上升沿以非阻塞赋值更新数据，模块于下一个上升沿锁存数据。每个核位置随后分 `ceil(CIN/LANES)` 轮累加，每轮包含 `LANES` 个乘法器，末组不足的通道屏蔽为零。

输出顺序为输出行、输出列、输出通道。`ofm_addr_o` 为输出空间位置加配置基址，`ofm_strb_o` 是 `KERNELS` 位通道独热码，`ofm_data_o` 是该通道量化值，`ofm_acc_o` 是同一通道量化前的累加值。`ofm_vld_o` 上升沿即写回沿；最后写回之后的一个周期才采样到 `cfg_conv_done_o`。

从采样启动沿到采样完成沿的周期差为：

```text
N = OH × OW × COUT
G = ceil(CIN / LANES)
cycles = N × [KERNEL_H × KERNEL_W × (G + 2) + 1] + 1
```

两拍额外开销分别为存储请求与数据锁存，每个输出额外一拍写回。测试平台使用 10 ns 时钟，并逐次比较此公式。

## 自校验平台

`../tb/tb_conv.sv` 接受相同尺寸参数，另有 `RUNS`、`RESET_BETWEEN_RUNS` 与三个非零地址基址参数。默认连续完成两次完整任务，并在两次之间复位；将 `RESET_BETWEEN_RUNS=0` 可检查无需复位的重复启动。

必需运行参数为 `+IFM=... +KERNEL=... +GOLDEN=... +GOLDEN_ACC=... +OUTPUT=... +METRICS=...`。量化参考和累加参考文件均按输出空间逐行打包，通道 0 在最低位，每通道分别占 8 位与 32 位。平台同时检查有符号值、原始累加、地址范围、通道独热码、写回次序、未知值、重复/缺失输出、完成时机和超时。

可选 `+VCD=... +TRACE_CYCLES=400` 只记录启动附近的有限控制信号波形，在最后输出附近重新打开，不转储大存储器。机器可读指标保存最后一次完整任务的 `cycles`、`expected_cycles`、`output_count`、`errors`、成功运行次数 `runs`、`lanes` 与 `clock_period_ns`。输出文件无 `$writememh` 地址注释，每行一个打包输出字。

## 已验证范围与限制

快速回归覆盖 1×1、2×3、3×3、5×5 卷积核，矩形输入、padding 为 0/1/2、步幅 1/2、输入通道不能整除并行数、`COUT<KERNELS`、正负饱和、负数算术右移，以及带复位和不带复位的重复启动。`LANES=1/4/16` 均有独立仿真与综合证据，快速回归另覆盖 `LANES=8`。

`LANES` 可以是任意正整数，`CIN` 不要求整除；核高宽独立配置，实际有效条件是正整数输入/核/步幅、非负 padding、正输出尺寸及 `1<=COUT<=KERNELS`。配置须保持 `OH,OW` 与卷积尺寸公式一致。三个地址空间的访问范围必须处于 20 位地址内。`SHIFT` 应设为 0 到 31；不执行四舍五入。32 位累加按二进制补码自然回绕，前端选取的维度须使数学累加不溢出 int32；课程和回归参数满足该条件。

`python conv_sim/scripts/validate.py` 可复现无复位重启、损坏参考文件故障注入，以及 `LANES=1/4/16` 的 Yosys `proc/opt/check/stat` 检查。日志、工具版本和 JSON 汇总保存在 `results/validation/`，临时网表自动清理。资源统计是通用 RTL 单元级估算，未映射具体 FPGA/ASIC 库；汇总按乘法器输入宽度识别 8×8 数据乘法器，避免把地址运算混入并行 MAC 数量。
